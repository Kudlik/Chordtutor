# Bugs

A simple log of known bugs. Add a new row to **Open** when you find one, and move it to **Fixed** when the fix reaches `main`.

- **ID**: next free number, `BUG-001`, `BUG-002`...
- **Severity**: `critical` (app unusable or wrong chord notes), `major` (feature broken), `minor` (cosmetic or rare).
- **Area**: `theory`, `voicings`, `fretboard`, `explanation`, `i18n`, `settings`, `analytics`, `pwa`, `layout`.
- **Story**: the related `@US-xxx` tag from `features/`, if any.

## Report template

Copy this block under the table, with the same ID as the row:

```md
### BUG-000: short title

- **Found on**: branch / URL, date
- **Device and browser**: e.g. iPhone 15, Safari 18
- **Chord, instrument, language, theme**: e.g. G 7, Ukulele, Polish, Dark
- **Steps to reproduce**:
  1. ...
- **Expected**: ...
- **Actual**: ...
- **Screenshot**: ...
```
